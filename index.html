CSV 형식

팀 제어 코드 HESS_controlB.ino(v4)가 SD카드에 남기는 LOG000.CSV를 그대로 넣으면 됩니다. v2·v3의 기록 파일도 읽을 수 있어요.

열 이름의미재는 부품
ms켠 뒤 지난 시간 (밀리초)Arduino
modePROD 생산 · STORE 저장 · USE 사용선택 스위치 (A0·A1)
h2_ppm수소 농도 (ppm)H₂ 센서 (I2C 0x74)
el_V, el_A수전해 E205 입력 전압, 전류#30-1 전력계 (0x45)
fc_V, fc_A연료전지 F102 출력 전압, 전류#30-2 전력계 (0x40)
temp_C연료전지 온도 (°C)DS18B20 (A3)
bat_A배터리 전류 (충전 +, 방전 −)ACS712 (A2)
bat_stateCHG 충전 중 · USE 사용 중 · IDLE 정지bat_A로 판정
renew_A_est재생에너지 전류 추정 (배터리 + 수전해 입력)계산값

v4 코드가 파일 첫 줄에 쓰는 헤더

ms,mode,h2_ppm,el_V,el_A,fc_V,fc_A,temp_C,bat_A,bat_state,renew_A_est

다른 프로그램에서 만든 파일은 t,src_v,src_a,bat_v,bat_a,elz_v,elz_a,fc_v,fc_a,load_v,load_a,temp_fc,temp_bat,h2 열 이름도 읽습니다. 측정하지 않은 항목은 0으로 두면 '측정 안 함'으로 처리해요.
